# Temso plugins for Claude

This repository holds [Temso](https://www.temso.ai)'s plugins for Claude.

| Plugin | What it does |
|---|---|
| [`temso`](plugins/temso) | Market your brand to AI agents: AI visibility reports, pitch snapshots, improvement plans, and technical audit reviews from your live Temso data. |

## Install

- **claude.ai and Cowork:** find **Temso** in the Claude directory under **Customize → Plugins**.
- **Claude Code:**

  ```
  /plugin marketplace add Temso-AI/claude-plugins
  /plugin install temso@temso
  ```
